# About Azure Core Underground

Azure Core Underground is a **free, community-driven virtual conference** for Azure infrastructure professionals. Join us for deep technical sessions, expert insights, and networking opportunities.

![Azure Core Underground Logo](/assets/acu-logo.png)

## What to Expect

- **Deep technical sessions** on Azure infrastructure topics
- **Expert speakers** from the Azure community and Microsoft
- **Live Q&A** and interactive discussions
- **Networking opportunities** with peers and industry leaders
- **On-demand recordings** available after the event

## Who Should Attend

This event is perfect for:

- ☁️ Cloud architects and engineers
- 🔧 IT professionals working with Azure
- 🚀 DevOps and platform engineers
- 📚 Anyone interested in Azure infrastructure
- 🎓 Those preparing for Azure certifications

## Event Format

All sessions are delivered virtually via live stream. You can:

1. Watch sessions live and interact in real-time
2. Ask questions during Q&A segments
3. Access recordings after the event
4. Connect with speakers and attendees
